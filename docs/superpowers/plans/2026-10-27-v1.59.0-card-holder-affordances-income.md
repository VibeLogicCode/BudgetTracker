# Card holder first, affordances, Budgets income — Implementation Plan (v1.59.0)

**Goal:** At import a linked card holder beats a person rule (card > rule > account owner), and the
admin is told about unlinked card values and profiles with no cardholder column. Disclosures, back
links and card footer actions each get one shared look. Budgets header actions share one style and
fold into an "Actions" menu on phones, and Budgets gains an income line with typical income.

**Base:** v1.58.1 (the tag, after its fix round). Work on `main`, no branches or worktrees.

**Process:** Lane 0 first (one implementer, shared components only), committed by the orchestrator;
then Lanes 1-3, one fresh implementer each, in parallel, on the disjoint file sets listed. They run
only the tests they touch plus `tests/ops` and do not commit; the orchestrator commits each lane by
file name. Then ONE Opus review over the whole range, one fix round, then the release gate once.

## Global constraints

- PUBLIC repo: no owner name, employer, Windows paths, account names or real figures. Invent every
  fixture value (people `Alex` / `Sam`, merchants like `MAPLE GROCER`, `FUEL STOP 12`, card values
  like `CARD 1001`). No quotes of anyone in comments.
- `'use server'` files export only async functions; every action's first statement is its origin
  check (`tests/ops/use-server-exports`, `tests/ops/server-action-origin`).
- Mirror sibling code's helpers, messages and `ActionState` shapes. Buttons via `buttonClass`
  (`tests/ops/button-vocabulary`), lucide only via `src/components/ui/icons.tsx`, 44px floor as
  `min-h-11 sm:min-h-0`. Accessible names do not change: icons are `aria-hidden`, labels stay word
  for word (a `←` glyph becoming an icon is the only text change).
- No hooks in a component without `'use client'`; `src/lib/budget-income.ts` reads the database and
  stays out of client code (`tests/ops/client-bundle`). No `? 'household' : 'personal'` ternary
  (`tests/ops/budget-scope-branch`), no UTC date slicing (`tests/ops/no-utc-date-slice`).
- Tests use explicit dates, never today. Vitest 4 + Testing Library, no jest-dom.
- Never `git stash`, `git checkout -- <file>` or `git restore` (CRLF rewrite breaks ops guards).
